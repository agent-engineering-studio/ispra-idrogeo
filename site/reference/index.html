    API reference¶

    At a glance¶

    Name What it does
    IdroGEO(client=None, *, retries=3, backoff_s=2.0) The async client; opens (and closes) its own HTTP client if not given one.
    .fetch(dataset, directory=None, *, unpack=True) The dataset ready to read: the unpacked folder, or the file.
    .download(dataset, directory=None) Download(path, changed): the file, and whether this call changed it.
    .summary(summary, level, code=None) "iffi" counts or "pir" indicators; without code, the list of that level.
    .dictionaries() / .dictionary(name) The names of the code lists / one list.
    .landslide(id_frana) The full record of one validated landslide.
    .iter_landslides(filters, modified_since=, page_size=1000, select=, order="id_frana") Every matching IFFI landslide, page after page; only the changed ones with modified_since.
    .iter_events(filters, modified_since=, page_size=1000, select=, order="uid") Every matching landslide event, page after page.
    .sites(filters, modified_since=, select=) The monitoring sites (1,063).
    .site(uid) / .stations(uid) One site / its stations, instruments and sensors.
    .webcams(filters) The webcams pointed at landslides.
    .search_landslides(filters, limit=, offset=, select=, order=) One page of IFFI landslides.
    .search_events(filters, limit=, offset=, select=, order=) One page of validated landslide events.
    .municipalities(summary="pir", directory=None, *, concurrency=8, max_age=None) The summary of all 7,899 municipalities, saved one JSON per municipality.
    .summaries(summary, level, directory=None, *, concurrency=8, max_age=None) The same for every region, province or municipality.
    opendata(layer, area="ispra", fmt="shapefile") An open-data Dataset (URL + file name).
    mosaic("pai_frane" \| "idraulica") A national hazard mosaic.
    sensor_data() The monitoring network readings.
    REGIONS / PROVINCES / region_area(cod_reg) Area file names by ISTAT code.
    LANDSLIDE_LAYERS / EVENT_LAYERS / MOSAICS What there is.
    default_directory() Where downloads go when no directory is given.
    .lookup(kind, text, limit=10) Search geological units, flights, bibliography, institutions, funding.
    IdrogeoError IdroGEO answered, but not with what was asked for.
    .labels(name, lang) / .code_labels(fields, lang) / decode(record, labels) Code lists, and records with <field>_label added.
    ispra_idrogeo.geo.read(path) A downloaded file or folder as a GeoDataFrame (extra [geo]).
    ispra_idrogeo.geo.frame(rows, geometry="point") API rows as a GeoDataFrame, in their own CRS.
    ispra_idrogeo.geo.add_labels(frame, labels) <column>_label columns for coded columns.
    idrogeo-mcp An MCP server with the same data as 10 tools (extra [mcp]).
    idrogeo <command> The same from the shell: fetch, summary, municipalities, landslides, events, sites, webcams, landslide, labels, dictionaries.

    Lower level, for your own HTTP layer: summary_path, search_params, level_codes, since_filter, parse / parse_list, read_validators / write_validators, read_json / write_json, extract.

    The client¶

    IdroGEO ¶

    Open-data downloads into a persistent folder, and the read-only API.

    aclose async ¶

    aclose() -> None

    Close the HTTP client if this instance opened it.

    download async ¶

    download(
    dataset: Dataset, directory: Path | None = None
) -> Download

    The file in directory, downloaded only if missing or changed upstream.

    directory defaults to :func:~ispra_idrogeo.cache.default_directory. A 404 raises :class:IdrogeoError: the layer or area does not exist.

    fetch async ¶

    fetch(
    dataset: Dataset,
    directory: Path | None = None,
    *,
    unpack: bool = True,
) -> Path

    The dataset ready to read: the folder its ZIP unpacks to, or the file.

    The folder is <directory>/<dataset.stem> and is unpacked again only when the download changed (or the folder is missing).

    summary async ¶

    summary(
    summary: Summary, level: Level, code: int | None = None
) -> Any

    IFFI counts ("iffi") or hazard indicators ("pir"), or a level's list.

    summaries async ¶

    summaries(
    summary: Summary,
    level: Level,
    directory: Path | None = None,
    *,
    concurrency: int = 8,
    max_age: timedelta | None = None,
) -> list[dict[str, Any]]

    The summary of every region, province or municipality, kept on disk.

    One call lists the level, then one call per area (7,899 for "comuni", ~17 MB) asks for its summary, concurrency at a time. Each answer is saved in <directory>/<summary>_<level>/<code>.json and read back instead of asked again until it is older than max_age (never, by default), so an interrupted run resumes where it stopped. The result follows the order of the API's list.

    municipalities async ¶

    municipalities(
    summary: Summary = "pir",
    directory: Path | None = None,
    *,
    concurrency: int = 8,
    max_age: timedelta | None = None,
) -> list[dict[str, Any]]

    Hazard and risk indicators (or IFFI counts) of every municipality.

    :meth:summaries for "comuni": see there for the folder and max_age.

    dictionaries async ¶

    dictionaries() -> list[str]

    The names of the code lists.

    dictionary async ¶

    dictionary(name: str) -> Any

    One code list (IdrogeoError if it does not exist).

    labels async ¶

    labels(name: str, lang: Language = 'en') -> dict[str, str]

    One dictionary as {code: label} in lang (Italian where untranslated).

    code_labels async ¶

    code_labels(
    fields: Iterable[str] | None = None,
    lang: Language = "en",
) -> dict[str, dict[str, str]]

    {field: {code: label}} for :func:~ispra_idrogeo.codes.decode.

    fields defaults to every field in :data:~ispra_idrogeo.codes.CODE_DICTIONARIES; each dictionary is asked for once.

    lookup async ¶

    lookup(
    kind: Lookup, text: str, *, limit: int = 10
) -> list[Any]

    Search a reference list by text: geological units, flights, bibliography…

    kind is one of :data:~ispra_idrogeo.api.LOOKUPS. Most lists answer objects; "ordini" and "finanziamenti" answer names.

    landslide async ¶

    landslide(id_frana: str) -> dict[str, Any]

    The full record of one validated IFFI landslide (~140 fields).

    Causes, activations, state and velocity, damage, interventions, precursors: many fields are often empty. IdrogeoError if the id is unknown or the landslide is not public (IdroGEO answers 401, not 404, to both).

    iter_landslides ¶

    iter_landslides(
    filters: dict[str, Any] | None = None,
    *,
    modified_since: datetime | None = None,
    page_size: int = 1000,
    select: list[str] | None = None,
    order: str = "id_frana",
) -> AsyncIterator[dict[str, Any]]

    Every IFFI landslide matching filters, page after page.

    Filters take plain values ({"tipo_movimento": 6}). With modified_since only the landslides changed since then: the incremental update of a local copy (select=["*"] brings the geometry too). A landslide that is removed does not show up as changed, it just stops being listed.

    Pages are ordered by order so that they do not overlap; IdroGEO changes daily, so a record edited while you iterate may be seen twice or missed.

    iter_events ¶

    iter_events(
    filters: dict[str, Any] | None = None,
    *,
    modified_since: datetime | None = None,
    page_size: int = 1000,
    select: list[str] | None = None,
    order: str = "uid",
) -> AsyncIterator[dict[str, Any]]

    Every validated landslide event matching filters, page after page.

    Filters take operators ({"regione": "eq.16"}); see :meth:iter_landslides for modified_since and the order.

    sites async ¶

    sites(
    filters: dict[str, Any] | None = None,
    *,
    modified_since: datetime | None = None,
    select: list[str] | None = None,
) -> list[dict[str, Any]]

    The landslide monitoring sites matching filters (1,063 in all).

    Filters take operators ({"stato_monitoraggio": "eq.1"} for the active ones); modified_since keeps the sites changed since then. point is longitude and latitude (WGS 84); id_frane_correlati links a site to its IFFI landslides.

    site async ¶

    site(uid: str) -> dict[str, Any]

    One monitoring site by its uid ("SIPIE001"), not by its id.

    stations async ¶

    stations(uid: str) -> list[dict[str, Any]]

    The stations of a monitoring site, with their instruments and sensors.

    webcams async ¶

    webcams(
    filters: dict[str, Any] | None = None,
) -> list[dict[str, Any]]

    The webcams pointed at landslides (14, all in Lombardy in 2026).

    Filters take operators ({"regione": "eq.3"}). Mind geom: its coordinates are EPSG:3857 metres, not longitude and latitude.

    search_landslides(

    Sources: what there is to download¶

    sources ¶

    Where IdroGEO publishes its open data, as pure URL builders.

    The open-data downloads are the ones the IdroGEO web app links to under "Download massivo": /opendata/<group>/<layer>_<area>_opendata.zip, a shapefile, or ….json.zip for GeoJSON. <area> is ispra for the whole of Italy, or the file name of a region or province (:data:REGIONS, :data:PROVINCES). ISPRA regenerates them every day, with an ETag and a Last-Modified, so a conditional GET tells whether anything changed.

    The older paths /opendata/iffi/<region>/iffi_<region>_<layer>.zip and /opendata/iffi/dizionari/*.json answer 404 since 2026: the dictionaries are now served by the API (:mod:ispra_idrogeo.api).

    Coordinates in the files are in EPSG:32632 (WGS 84 / UTM zone 32N).

    Search filters¶

    filters ¶

    Search filters without the technical manual.

    Each IdroGEO search reads its JSON filter its own way, and the differences fail with cryptic messages. These builders know them (checked on the live service, November 2026):

    • landslides: most fields take operators ("eq.100", "in.(5,6)"), but tipo_movimento takes a plain number and no list. There is no reliable area filter: regione is a relation the search refuses, and regione_2019 is empty for 18% of the landslides (most of Campania). For an area, download opendata(layer, area).
    • events and sites: operators on every field, areas included; a range of dates is an "and" of two conditions.

    Every builder returns a plain dict for the filters argument of iter_landslides, iter_events, sites and webcams; combine it with modified_since there.

    landslide_filter ¶

    landslide_filter(
    *,
    movement: int | None = None,
    activity: Codes | None = None,
    district: Codes | None = None,
) -> dict[str, Any]

    Landslides by type of movement, state of activity, river basin district.

    movement is one tipo_movimento code (the search takes no list); activity the stato_attivita_1liv codes (100 active, reactivated or suspended; 200 dormant; 300 stabilised; 400 relict); district the autorita_distretto codes.

    event_filter ¶

    event_filter(
    *,
    region: Codes | None = None,
    province: Codes | None = None,
    municipality: Codes | None = None,
    movement: Codes | None = None,
    start: date | None = None,
    end: date | None = None,
) -> dict[str, Any]

    Landslide events by area (ISTAT codes), type of movement, date.

    start is included and end excluded, like a Python range: start=date(2023, 1, 1), end=date(2024, 1, 1) is the year 2023.

    site_filter ¶

    site_filter(
    *,
    region: Codes | None = None,
    province: Codes | None = None,
    municipality: Codes | None = None,
    active: bool | None = None,
) -> dict[str, Any]

    Monitoring sites by area (ISTAT codes) and whether active.

    Webcams take the area part too; they have no active.

    Code lists¶

    codes ¶

    Codes in the data, and the words they stand for.

    IFFI records, the open-data files and the monitoring sites store codes (tipo_movimento = 4); the API's dictionaries (/api/dizionari) say what each code means, in Italian, English, French and German. :data:CODE_DICTIONARIES says which dictionary decodes which field, and :func:decode adds a <field>_label next to each coded field.

    parse_labels ¶

    parse_labels(
    entries: Any, lang: Language = "en"
) -> dict[str, str]

    A dictionary's entries as {code: label}; Italian where a translation is missing.

    decode ¶

    decode(
    record: Mapping[str, Any],
    labels: Mapping[str, Mapping[str, str]],
) -> dict[str, Any]

    A copy of record with <field>_label next to each field in labels.

    labels maps a field to its {code: label} (see :meth:~ispra_idrogeo.IdroGEO.code_labels). A list of codes becomes a list of labels; an empty value stays None, and a code missing from the dictionary becomes None too rather than a guess.

    GeoDataFrames (extra [geo])¶

    geo ¶

    IdroGEO data as GeoDataFrames: pip install "ispra-idrogeo[geo]".

    :func:read opens what :meth:~ispra_idrogeo.IdroGEO.fetch unpacked; :func:frame turns API rows (landslides, events, sites, webcams) into a frame in the right coordinate system; :func:add_labels adds the words of the coded columns. frame.to_parquet(path) writes GeoParquet.

    read ¶

    read(path: Path, **kwargs: Any) -> Any

    A file or an unpacked folder (from fetch) as a GeoDataFrame.

    A folder must hold exactly one shapefile or GeoJSON. kwargs go to :func:geopandas.read_file (bbox=, columns=, rows=…).

    frame ¶

    frame(
    rows: Iterable[Mapping[str, Any]],
    geometry: Geometry = "point",
) -> Any

    API rows as a GeoDataFrame, geometry from geometry.

    "point" is [lon, lat] (EPSG:4326): landslides, sites. The GeoJSON fields ("geom", "geom_polygon", "geom_linestring") carry their own CRS: EPSG:32632 for landslides, EPSG:3857 for webcams. Rows without that geometry get an empty one rather than being dropped.

    add_labels ¶

    add_labels(
    data: Any, labels: Mapping[str, Mapping[str, str]]
) -> Any

    data with a <column>_label next to each coded column in labels.

    labels comes from :meth:~ispra_idrogeo.IdroGEO.code_labels; lists of codes become lists of labels, unknown codes None.

    The MCP server (extra [mcp])¶

    mcp_server ¶

    An MCP server over IdroGEO, for AI agents: pip install "ispra-idrogeo[mcp]".

    idrogeo-mcp            # stdio, for Claude Desktop, IDEs, agent frameworks

    Every tool reads the public API (no account), except download_dataset, which writes the file to the local download folder and returns its path. Codes come back with their English labels, and long answers are cut at limit rows, so an agent never receives 700,000 landslides at once.

    server ¶

    server(idrogeo: IdroGEO | None = None) -> MCPServer[Any]

    The MCP server; idrogeo defaults to a client it opens and closes itself.

    main ¶

    main() -> None

    Entry point of idrogeo-mcp.

    Low level: requests, parsers, cache¶

    api ¶

    The IdroGEO REST API (/api), as pure request builders and parsers.

    Reading needs no account; only writes and a few detail endpoints ask for a login. Summaries and hazard indicators exist for Italy, macro-regions, regions, provinces and municipalities (ISTAT codes); the dictionaries are the code lists the files use (movement types, causes, damage, …).

    Searches take a JSON object of filters whose syntax is described in ISPRA's technical manual; an empty object matches everything, so always page with limit and offset.

    summary_path ¶

    summary_path(
    summary: Summary, level: Level, code: int | None = None
) -> str

    iffi/regioni/16; without code, the list of that level (italia takes none).

    level_codes ¶

    level_codes(
    level: Level, items: list[dict[str, Any]]
) -> list[int]

    The ISTAT codes in the list of a level, in the order the API gives them.

    since_filter ¶

    since_filter(
    filters: dict[str, Any] | None, since: datetime | None
) -> dict[str, Any]

    filters plus "modified at or after since", for incremental updates.

    since must carry a time zone (datetime.now(UTC)): IdroGEO stores modified in UTC, and a naive time would be read in the server's.

    lookup_params(
    kind: str, text: str, limit: int

    The query string of a text search in a reference list.

    search_params ¶

    search_params(
    *,
    limit: int,
    offset: int = 0,
    select: list[str] | None = None,
    order: str | None = None,
) -> dict[str, str]

    The query string of a search.

    parse ¶

    parse(status_code: int, body: bytes | str) -> Any

    The decoded JSON of a 200; :class:IdrogeoError with the API's message otherwise.

    parse_list ¶

    parse_list(
    status_code: int, body: bytes | str
) -> list[dict[str, Any]]

    A JSON list of objects (searches, level lists).

    cache ¶

    The persistent download folder, and what it remembers about each file.

    Next to every downloaded file sits <file>.meta.json with the URL and the ETag / Last-Modified the server sent. They become the If-None-Match / If-Modified-Since of the next request, so a file that has not changed is answered 304 and costs no download.

    Validators dataclass ¶

    What the server said about the copy on disk.

    headers ¶

    headers() -> dict[str, str]

    The conditional-request headers for the next download.

    default_directory ¶

    default_directory() -> Path

    Where downloads go when no directory is given.

    IDROGEO_DATA_DIR if set, else ispra-idrogeo in the user cache ($XDG_CACHE_HOME, or ~/.cache). Use a folder that survives restarts: the national files weigh hundreds of MB.

    read_validators ¶

    read_validators(path: Path, url: str) -> Validators | None

    The validators of a file on disk, or None if it cannot be revalidated.

    A file without metadata, with unreadable metadata, or downloaded from another URL is downloaded again rather than trusted.

    read_json ¶

    read_json(
    path: Path, max_age: timedelta | None = None
) -> Any | None

    A saved API answer, or None if missing, unreadable or older than max_age.

    write_json ¶

    write_json(path: Path, data: Any) -> None

    Save data as JSON, atomically: a reader finds the old file or the new one.

    extract ¶

    extract(archive: Path, folder: Path) -> Path

    Unpack a ZIP into folder, replacing what was there; folder.

    The new content is unpacked beside the old one and swapped in only when complete, so a reader never finds half a shapefile. Members that would land outside folder raise :class:IdrogeoError.

    The one exception this package raises for answers it cannot use.
